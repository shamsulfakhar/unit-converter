# 📐 Engineering Unit Converter

A modern, precision-focused web application designed to help engineers and students convert common units of measurement instantly.

**[🔴 LIVE DEMO: Click here to view the site](https://shamsulfakhar.github.io/unit-converter/)**

## ✨ Features

* **Multi-Category Support:** Convert between Length, Mass, and Temperature units.
* **Engineering Precision:** Handles complex floating-point calculations with formatted output (4 decimal places).
* **Save Functionality:** Users can save frequently used conversions to a "Favorites" list for quick reference.
* **Responsive Design:** Fully responsive layout that works on desktops, tablets, and mobile devices.
* **Modern UI:** Clean, cheerful light-themed interface designed for readability and ease of use.

## 🛠️ Technologies Used

* **HTML5:** Semantic structure.
* **CSS3:** Custom variables, Flexbox for layout, and modern styling (no frameworks used).
* **JavaScript (ES6+):** DOM manipulation, event handling, and conversion logic.
* **Git & GitHub:** Version control and hosting.
